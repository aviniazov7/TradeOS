# מפת המסכים · TradeOS החדש

> טיוטה לאישור. מגדיר אילו מסכים יהיו באפליקציה החדשה ולאן עבר כל דבר מהישן.

## המבנה: 4 טאבים למטה + תפריט "עוד"

```
🏠 בית        📓 יומן        🧠 מאמן AI        👤 פרופיל       ⋯ עוד
```

---

## 🏠 בית — "התדרוך היומי"  (במקום הדשבורד הישן)
- תדרוך יומי מהמאמן (הכרטיס הכחול)
- 📈 **עסקה פתוחה עכשיו** + פס מסלול (כניסה → יעד/סטופ, רווח/הפסד חי)
- תמונת ביצועים מורחבת (רווח, win-rate, R:R, רווח/הפסד ממוצע, הכי טוב) — מסונכרן מהבורסה
- 📋 עסקאות אחרונות שנסגרו
- מד משמעת/טילט
- "מה לעשות היום" (פעולות)

## 📓 יומן
- רשימת עסקאות + הוספה/עריכה  *(היום: יומן עסקאות)*
- בק-טסטינג — טאב-משנה  *(היום: מסך נפרד)*

## 🧠 מאמן AI  (מאחד את כל הניתוח + הפסיכולוגיה)
- 💬 צ'אט עם המאמן  *(חדש)*
- 🔍 תובנות ודפוסים  *(חדש)*
- 📊 ניתוח וסטטיסטיקות  *(היום: סטטיסטיקות + trade-ai)*
- 🧘 אזור פסיכולוגיה: כוונת בוקר, סקירת ערב, מסע רגשי  *(היום: "אזור מנטליות")*
- 🎯 אסטרטגיות + סיגנלים  *(היום: מסכים נפרדים)*

## 👤 פרופיל
- פרטים אישיים  *(היום: פרופיל)*
- הגדרות + חיבור בורסה  *(היום: הגדרות/exchange)*
- פרימיום  *(היום: פרימיום)*
- 🌐 שפה (עברית/English)  *(חדש)*
- ♿ נגישות

## ⋯ עוד  (הקומודיטי — יורד מהליבה, נשאר נגיש)
- חדשות · נתוני שוק · ווטצ'ליסט · DCA · ארנקים · לוויתנים

## נפרד / מערכת
- `/admin` — פאנל ניהול · `/login` · דף נגישות ציבורי · מדיניות החזרים
